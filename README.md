# The Systems We Live In

A video series about the AI systems in our house — told from the basic setup to where we are now.

One person, one house machine, and a growing set of AI systems: a shared memory every agent reads, a council of named agents with real jobs, a decision shelf that keeps the human in charge, and an operating system taking shape around all of it. The series shows the real systems on screen — what works, what is still being built, and the seams, labeled as seams.

**Status: in production.** Episode 1 is in preparation. Nothing here claims an episode exists until it ships.
